## Setup Instructions

1. Create a Google Form for lead capture
2. Create a Google Sheet with columns: Name, Email, Phone, Property Type, Location, Budget, Timeline, AI Priority, AI Summary, Status, Email Sent
3. Connect Google Form to Make.com via webhook
4. Add Gemini module to classify leads
5. Add Google Sheets module to update rows
6. Add Gmail module to send follow-up emails
7. Test with fake data
